SECTION 1 — PROJECT OVERVIEW
----------------------------------------------------------------

Project Name     : Coding Profile Analyser
Project Type     : Full Stack Web Application (MERN)
Developer        : Hruthik
Technology Stack : MongoDB, Express.js, React.js (Vite), Node.js,
                   Tailwind CSS, Recharts, Framer Motion,
                   React Hot Toast, Axios, Mongoose, node-cache
Deployment       : Vercel (frontend) + Render (backend)
                   + MongoDB Atlas (database)
Purpose          : To pull public coding stats from multiple
                   platforms into one dashboard with a single
                   weighted score, and to demonstrate real-world
                   MERN skills (API integration, caching, auth-
                   free public data fetching, deployment) for a
                   portfolio.

SECTION 3 — FUNCTIONAL REQUIREMENTS
----------------------------------------------------------------

FR-01  HOME PAGE — PROFILE INPUT
  FR-01.1  Input field for LeetCode username
  FR-01.2  Input field for GitHub username
  FR-01.3  Input field for GeeksForGeeks username
  FR-01.4  Input field for HackerRank username
  FR-01.5  Input field for CodeChef username (reserved, disabled
            for future release)
  FR-01.6  Single "Analyse" button triggers all platform fetches
  FR-01.7  Loading state shown while fetching
  FR-01.8  Recent searches list shown below the form, re-runnable
            with one click

FR-02  ANALYSE / DATA FETCH
  FR-02.1  POST /api/analyse/leetcode fetches LeetCode stats
  FR-02.2  POST /api/analyse/github fetches GitHub stats
  FR-02.3  POST /api/analyse/gfg fetches GeeksForGeeks stats
  FR-02.4  POST /api/analyse/hackerrank fetches HackerRank stats
  FR-02.5  POST /api/analyse/all fetches all four platforms in
            parallel and returns a combined result
  FR-02.6  Each platform failure is isolated — one platform
            failing does not block the other platforms' results
  FR-02.7  Each response includes a cached flag and cachedAt
            timestamp

FR-03  LEETCODE DATA
  FR-03.1  Total problems solved
  FR-03.2  Easy / Medium / Hard solved counts
  FR-03.3  Acceptance rate
  FR-03.4  Global ranking
  FR-03.5  Contest rating (where available)
  FR-03.6  Estimated top percentage
  FR-03.7  Falls back to LeetCode's own GraphQL endpoint if the
            community stats API is unavailable

FR-04  GITHUB DATA
  FR-04.1  Public repository count
  FR-04.2  Followers / following count
  FR-04.3  Total stars across repositories
  FR-04.4  Top languages used (from most recently pushed repos)

  FR-04.6  Total contributions in the last year

FR-05  GEEKSFORGEEKS DATA
  FR-05.1  Coding score
  FR-05.2  Problems solved

FR-06  HACKERRANK DATA

  FR-06.2  Certifications (list + count)

FR-07  OVERALL SCORE
  FR-07.1  Weighted score out of 100 combining all four platforms

  FR-07.2  Per-platform breakdown shown as progress bars
  FR-07.3  Score displayed as an animated circular gauge

FR-08  STRENGTHS / WEAKNESSES / SUGGESTIONS
  FR-08.1  Auto-derived list of strengths (e.g. languages,
            algorithmic ability)
  FR-08.2  Auto-derived list of weaknesses
  FR-08.3  Actionable improvement suggestions list

FR-09  RESULTS DASHBOARD
  FR-09.1  Overall score gauge + breakdown bars
  FR-09.2  LeetCode card with Easy/Medium/Hard donut chart
  FR-09.3  GitHub card with language pie chart + contribution
            heatmap
  FR-09.4  GFG card with score/rank/streak stat badges
  FR-09.5  HackerRank card with badges and certifications
  FR-09.6  Save-profile form (name input + Save button)
  FR-09.7  Loading skeletons shown while cards are fetching
  FR-09.8  Error card shown per-platform on fetch failure

FR-10  SAVED PROFILES
  FR-10.1  POST /api/profiles/save stores a named profile snapshot

  FR-10.4  DELETE /api/profiles/:id removes a profile

  FR-10.7  Delete button removes a profile with confirmation

  FR-11.3  Winner marked per category (LeetCode solved, GitHub

SECTION 5 — CONSTRAINTS & ASSUMPTIONS
----------------------------------------------------------------

CONSTRAINTS
  - No authentication / login system (public usernames only,
    no per-user accounts in this version)
  - GeeksForGeeks and HackerRank have no official public APIs;
    data comes from unofficial community APIs and HTML scraping,
    which may break if those sites change their markup
  - LeetCode's free community stats API (Heroku-hosted) is not
    guaranteed to be always available
  - GitHub's REST API is rate-limited to 60 requests/hour without
    a personal access token
  - Render's free tier spins down after inactivity, causing a
    30-50 second delay on the first request after idle time

ASSUMPTIONS
  - Users provide real, public usernames that exist on each
    platform
  - Users have a stable internet connection
  - Project is for portfolio/demo purposes, not production scale
  - Profile data is public and does not require the platform
    owner's explicit consent to fetch

SECTION 8 — GLOSSARY
----------------------------------------------------------------

Platform    : One of LeetCode, GitHub, GeeksForGeeks, HackerRank
Overall Score: Weighted 0-100 score combining all four platforms
Cache hit   : A platform response served from memory instead of
              re-fetching from the source site
Scraping    : Extracting data from a public HTML page when no
              official API exists (used for GFG and HackerRank)
Saved profile: A named snapshot of a user's analysed stats,
              stored in MongoDB for later comparison/leaderboard
node-cache  : In-memory key-value cache used to avoid re-hitting
              external platform APIs too frequently
