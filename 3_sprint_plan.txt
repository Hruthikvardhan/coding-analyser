SPRINT 1 — BACKEND SETUP + MODELS + PLATFORM SERVICES
Duration : Day 1–2
Goal     : Express server runs, connects to MongoDB, and can
           fetch real data from LeetCode + GitHub
================================================================

TASK-001  Initialize Node/Express project                [P1] [ ]
  - npm init in server/ folder
  - npm install express mongoose dotenv cors helmet morgan
  - npm install axios cheerio node-cache
  - npm install -D nodemon
  - Verify: npm run dev starts server without errors
  Estimated time: 20 min

TASK-002  Create folder structure                        [P1] [ ]
  Create these folders under server/:
  - models/  controllers/  routes/  services/
  - middleware/  config/
  Estimated time: 5 min

TASK-003  Create config/database.js                      [P1] [ ]
  - mongoose.connect() using MONGO_URI from .env
  - Log connection success/failure clearly
  - Exit process on connection failure
  Estimated time: 15 min

TASK-004  Create .env.example                            [P1] [ ]
  - PORT, MONGO_URI, CLIENT_URL, CACHE_TTL_SECONDS
  - Document each variable's purpose
  Estimated time: 10 min

TASK-005  Create models/Profile.js                       [P1] [ ]
  - Fields: name, leetcode, gfg, github, hackerrank, codechef,
    savedAt, leetcodeData, githubData, gfgData, hackerrankData,
    overallScore (Mixed type for raw platform JSON)
  - Index on overallScore for leaderboard sorting
  Estimated time: 20 min

TASK-006  Create models/Search.js                        [P1] [ ]
  - Fields: platform, username, searchedAt, resultData,
    cacheExpiry
  - Index on platform + username
  Estimated time: 10 min

TASK-007  Create middleware/errorHandler.js               [P1] [ ]
  - Custom ApiError class with statusCode
  - notFound middleware for unmatched routes
  - Central errorHandler middleware returning JSON error shape
  Estimated time: 20 min

TASK-008  Create middleware/cacheMiddleware.js             [P1] [ ]
  - node-cache instance with 1 hour default TTL
  - getOrFetch(platform, username, fetchFn) wrapper
  - Returns { data, cached, cachedAt }
  Estimated time: 25 min

TASK-009  Create services/leetcodeService.js               [P1] [ ]
  - Fetch from leetcode-stats-api.herokuapp.com
  - Retry with backoff (2 retries) on failure
  - Fallback to LeetCode's own GraphQL endpoint if community
    API fails, pulling solved counts, acceptance rate, ranking,
    and contest rating
  - Return null-safe fields (use null, not 0, for unknowns)
  Estimated time: 60 min

TASK-010  Create services/githubService.js                 [P1] [ ]
  - Fetch user profile from GitHub REST API
  - Fetch up to 100 repos, compute total stars + top languages
  - Scrape real contribution calendar from GitHub's public
    /users/{username}/contributions page (data-date/data-level)
  - Handle 404 (user not found) and 403 (rate limit) explicitly
  Estimated time: 50 min

TASK-011  Create services/gfgService.js                    [P2] [ ]
  - Try unofficial community JSON API first
  - Fall back to scraping the public practice profile page
  - Throw a clear ApiError if both sources fail
  Estimated time: 35 min

TASK-012  Create services/hackerrankService.js              [P2] [ ]
  - Scrape public profile page for badges + certifications
  - Throw a clear ApiError if the profile is private/not found
  Estimated time: 30 min

SPRINT 1 DONE WHEN:
  ✓ npm run dev starts without errors
  ✓ MongoDB connects successfully (local or Atlas)
  ✓ Calling fetchLeetCodeStats('neetcode') returns real data
  ✓ Calling fetchGitHubStats('torvalds') returns real data
  ✓ GFG/HackerRank services return either real data or a clear
    ApiError (never crash the process)

SPRINT 2 — CONTROLLERS + ROUTES + CACHING + SCORE ENGINE
Duration : Day 3–4
Goal     : Full REST API working end-to-end via Postman/curl
================================================================

TASK-013  Create services/scoreCalculator.js                [P1] [ ]
  - leetcodeScore(), githubScore(), gfgScore(),
    hackerrankScore() — each normalised to 0-100
  - calculateOverallScore() — weighted 40/30/20/10 combine
  - deriveInsights() — strengths / weaknesses / suggestions
    generated from the score breakdown and raw platform data
  Estimated time: 45 min

TASK-014  Create controllers/analyseController.js            [P1] [ ]
  - One handler per platform (leetcode/github/gfg/hackerrank)
    wrapping getOrFetch() + logging to Search collection
  - getAll() — fetch all 4 platforms in parallel with
    Promise.all, isolate failures per platform (safeFetch)
  - Compute overall score + insights in the /all response
  Estimated time: 50 min

TASK-015  Create controllers/profileController.js            [P1] [ ]
  - saveProfile() — POST /api/profiles/save
  - getProfiles() — GET /api/profiles (sorted by savedAt desc)
  - getProfileById() — GET /api/profiles/:id
  - deleteProfile() — DELETE /api/profiles/:id
  Estimated time: 30 min

TASK-016  Create controllers/statsController.js               [P1] [ ]
  - compareProfiles() — category-by-category diff with
    per-category winner ('p1' / 'p2' / 'tie')
  - getLeaderboard() — overall + per-platform rankings
  Estimated time: 40 min

TASK-017  Create routes/analyseRoutes.js                      [P1] [ ]
  - POST /leetcode /github /gfg /hackerrank /all
  Estimated time: 10 min

TASK-018  Create routes/profileRoutes.js                      [P1] [ ]
  - POST /save, GET /, GET /:id, DELETE /:id
  Estimated time: 10 min

TASK-019  Create routes/statsRoutes.js                         [P1] [ ]
  - GET /compare, GET /leaderboard
  Estimated time: 10 min

TASK-020  Wire up server.js                                    [P1] [ ]
  - helmet, cors (CLIENT_URL from env), express.json, morgan
  - GET /api/health check route
  - Mount all three route groups under /api
  - notFound + errorHandler as final middleware
  - connectDB() then app.listen()
  Estimated time: 25 min

TASK-021  API smoke test (Postman / curl)                      [P1] [ ]
  - POST /api/analyse/all with real usernames → 200 + score
  - POST /api/profiles/save → 201 + saved document
  - GET /api/profiles → returns saved profile
  - GET /api/stats/leaderboard → sorted list
  - GET /api/stats/compare?id1=...&id2=... → category winners
  Estimated time: 30 min

SPRINT 2 DONE WHEN:
  ✓ All REST endpoints return correct JSON shapes
  ✓ Overall score calculation matches the documented weights
  ✓ A profile can be saved, listed, fetched by id, and deleted
  ✓ Compare and leaderboard endpoints work against saved data
  ✓ Repeated analyse calls within an hour show cached: true
