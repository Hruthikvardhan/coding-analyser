================================================================
PAPER DRAWING TIPS
================================================================

When drawing on paper:

1. Use a ruler for clean boxes
2. Draw outer page boundary first
3. Fill sections top → bottom
4. Use different pen colors:
   - Black pen: layout boxes and text
   - Amber/yellow pen: interactive elements (buttons, links,
     score numbers)
   - Red pen: error states and failed-fetch cards
   - Pencil: notes and annotations

5. Mark dimensions roughly:
   - Navbar: full width, ~60px tall
   - Platform card grid: 2 columns desktop, 1 column mobile
   - Score gauge: roughly 160px diameter circle

6. Use these symbols consistently:
   [  ] = button
   {  } = input / select dropdown
   (  ) = chart / gauge / icon
   🏆   = rank / winner marker
   ←   = annotation arrow
